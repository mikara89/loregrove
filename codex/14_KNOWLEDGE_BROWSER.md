# Prompt 14 — Knowledge Browser

Implement Knowledge navigation and node detail.

Show canonical name, aliases, summary, relationships, assertions, supporting/contradicting evidence, related sources, revision history and unresolved review items.

All manual corrections go through change sets.

Add user-authored Markdown notes as Tier-1 evidence and index them. Add backlinks among notes/nodes/sources.

Acceptance: user can understand why a node/claim exists and trace it to evidence.
